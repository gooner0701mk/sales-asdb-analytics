# 新規営業分析（ユーザー別・活動ログ版）

画面上部のタブで **「分析・活動記録」** と **「アプローチ先企業一覧」** を切り替えられます。

- **分析・活動記録** … 従来どおり。左から活動入力、グラフ・会社マイルストーンなど。
- **アプローチ先企業一覧** … 企業名・前回アプローチ日を登録し、**経過日数**が大きい順に一覧（久しぶりのアプローチ先が上に来る）。「自分のみ」では担当に紐づく企業だけ、「全員」では担当列付きで全件。

データは `approachTargets` 配列として JSON 全状態に含まれます。

左から**活動ごと**に入力。集計・グラフは活動日の年月で自動集計。複数の**営業ユーザー**を追加し、「**自分のみ**」「**全員**」で表示を切り替えられます。

保存はブラウザの `localStorage`（キー: **`sales-newbiz-v5`**）。初回に旧 `sales-newbiz-v4` がある場合は自動で v5 に移行します（担当1名に紐づけ）。

## 会社全体の日付

`companyMilestones` で **会社単位の前回アプローチ日・前回受注日** を保持します（JSON エクスポートに含まれる）。

- **経過日数** … 手入力があればそれを、なければログ（全ユーザーの活動）から推定した日付を基準に、今日からの経過を表示します。
- **受注の翌日以降、最初の飛び込み／テレアポまでの日数** … 上記の基準「前回受注日」より後の日付にある飛び込み・テレアポのうち最も早い1件までの日数です（商談のみの活動はカウントしません）。

## 起動

```bash
cd sales-newbiz-analytics
npm install
npm run dev
```

## ユーザー

- **記録する担当** … プルダウンで選択。新規活動はこのユーザーに紐づきます。
- **ユーザーを追加** … 名前を入力して追加。追加後、そのユーザーに切り替わります。
- **このユーザーを削除** … そのユーザーの活動が **0件** のときのみ可能。
- **自分のみ / 全員** … 右側のカード・グラフ・左の活動一覧の対象範囲。活動の追加は常に「記録する担当」。

※ログイン認証はありません。同一PC・同一ブラウザ内の共有前提です。

## 率の定義

| 名称 | 計算 |
|------|------|
| 営業件数 | 飛び込み ＋ テレアポ ＋ 商談（活動回数の合計） |
| 営業件数に対する見積率 | 見積件数合計 ÷ 営業件数（100%超え得る） |
| 見積に対する受注率 | 受注件数合計 ÷ 見積件数合計 |

## 活動ログ CSV

`date,customerName,activityType,quoteCount,orderCount,userId`

- `userId` が無い行は、取り込み時に選択中ユーザーの ID が付きます。

## 全状態 JSON

`version: 5`（`users`, `sessionUserId`, `viewScope`, `activities`, `milestonesByUser`）。
